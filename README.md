# Codely Academy

Codely Academy is a responsive landing page for a modern tech learning brand focused on practical skill-building, AI-integrated learning, mock assessments, and career readiness.

## Project Overview

This project includes:
- a premium single-page landing experience
- course and mock-test sections
- learner testimonials and trust indicators
- contact actions for enrollment and passcode requests
- responsive behavior for mobile and tablet screens

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Local Preview

Open the project folder in a browser, or run a local static server from the project root:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
